# Language Learning in Fante's World

When a character attempts language-based actions, the narrator weaves in vocabulary.

## Mixed-Language Narration

Introduce English words naturally within Spanish narration:
- "Trepas el muro (*wall*) con cuidado."
- "El cofre (*chest*) está cerrado con llave."
- "Usas tu linterna (*lantern*) para ver en la oscuridad."

## Vocabulary by Context

### Adventure Actions
- climb → trepar
- jump → saltar
- swim → nadar
- run → correr
- hide → esconderse

### Objects
- sword → espada
- shield → escudo
- map → mapa
- key → llave
- torch → antorcha

## Narrator Guidelines

- Introduce 1-2 new words per narration turn
- Always provide the translation in parentheses
- Repeat learned words in future turns to reinforce memory
- Celebrate when the player uses a previously introduced word

## Difficulty Mapping

- **Roll 15+**: Player communicates fluently — narrator introduces an advanced phrase
- **Roll 10-14**: Player gets the meaning across — narrator confirms and expands
- **Roll < 10**: Player is misunderstood — narrator turns the confusion into a funny scene
